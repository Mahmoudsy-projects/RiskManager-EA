# Hub MT5 1.13 — تم‌های ۸ تا ۱۰ + تغییر تم ۴   [کامپایل نشده]

## چه چیزی عوض شد
- سه تم جدید (۸ = سیاه روی سفید، ۹ و ۱۰ = سفید با رنگ‌های سبز/قرمز ملایم) با مقادیر دقیقی که فرستادید.
- در تب Theme، دکمه‌های ۸، ۹، ۱۰ در سه جای خالی ردیف دوم، زیر دکمه‌های Indicator / Label / Draw قرار گرفتند؛ شبکه‌ی ۱..۷ + Original مثل قبل. عرض پنل تغییری نکرد.
- چیدمان یکدست: همه‌ی ۱۱ دکمه‌ی تب Theme هم‌اندازه‌اند (عرض = یک‌سوم عرض چهار دکمه‌ی مادر). سه دکمه‌ی ۸/۹/۱۰ دقیقاً زیر مادرها را پر می‌کنند و جای خالی نمی‌ماند؛ شبکه‌ی ۱..۷ + Original همین اندازه را دارد. عرض کل پنل در این تب کمی بیشتر می‌شود.
- تم ۴ طبق مقادیر جدید شما عوض شد (Background مشکی، BarUp سفید، BarDown خاکستری ۱۰۲، Bear مشکی، Bid/Last نقره‌ای).
- Line/Volumes/Ask/Stop حالا برای هر تم جدا تعریف می‌شود. تم‌های جدید Bid و Last را هم ست می‌کنند.
- Original با فرمت جدید TO2 (۱۳ رنگ) ذخیره می‌شود تا Bid/Last هم برگردد. Originalهای ذخیره‌شده با فرمت قبلی (از Hub 1.12) هنوز خوانده می‌شوند و Bid/Last را دست نمی‌زنند.
- تم‌های ۱ تا ۳ و ۵ تا ۷ بدون هیچ تغییری (Bid/Last را دست نمی‌زنند).

## تست‌ها
1. تب Theme را باز کنید: دکمه‌های ۸، ۹، ۱۰ زیر Indicator/Label/Draw دیده شوند و ردیف بالا و Original سر جایشان باشند.
2. هر یک از ۱۰ تم را بزنید: رنگ‌ها با مقادیر شما بخوانند (Properties → Colors)؛ برای ۴، ۸، ۹، ۱۰ مقدار Bid و Last هم درست باشد.
3. بعد از تم ۸/۹/۱۰ روی Original بزنید: همه‌ی رنگ‌ها شامل Bid و Last به حالت اولیه برگردند. (برای چارتی که Original قبلاً با Hub 1.12 ذخیره شده، Bid/Last همان‌طور که تم گذاشته بود می‌ماند، که طبیعی است.)
4. اندیکاتورها و ابزارهای Hub (EMA، Key Time، Label …) بعد از تم‌های روشن ۸/۹/۱۰ خوانا باشند.
5. تایم‌فریم را عوض کنید یا Hub را دوباره بگذارید: تم فعال درست شناسایی شود (دکمه‌ی روشن).
