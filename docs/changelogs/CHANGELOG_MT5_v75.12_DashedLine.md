# EA MT5 v75.12 — خط‌چین شدن خط ابتدا–انتهای R/R و Measure Move   [کامپایل نشده]
در Properties هر دو ابزار، استایل خط وصل نقطه‌ی اول به دوم روی خط‌چینِ ریز (Dot) قرار می‌گیرد (هم پیش‌نمایش هم نسخه‌ی نهایی). سطوح (لول‌ها) همچنان ممتد می‌مانند. MT4 در بسته‌ی MT4 (v108) همین را می‌گیرد.
تست: ابزار R/R و Measure Move را بگذارید؛ خط بین دو نقطه‌ی اصلی خط‌چین باشد و در Properties → Style = Dot (خط‌چین ریز)؛ لول‌ها ممتد.
فایل: RM_Tools.mq5 (دو تابع CreateFiboRMultiple و CreateFiboMeasureMove)
