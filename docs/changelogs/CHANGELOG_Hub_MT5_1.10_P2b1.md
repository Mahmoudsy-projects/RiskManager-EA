# Hub MT5 1.10 — ابزارهای ترسیم جدید + Weekly Map ادامه‌دار (P2b-1)
(پورت از MT4 Hub 1.15؛ کامپایل‌نشده — اول کامپایل کن)

## چه اضافه شد
1. **Horizontal Line** (تب Draw): یک کلیک → خط افقی از نقطه‌ی کلیک تا بی‌نهایت سمت راست؛ بعد از رسم ابزار تمام می‌شود.
2. **Dash Line** (تب Draw): مثل Line (دو کلیک، پیش‌نمایش، Shift-snap) ولی خط‌چین نازک.
   - هر دو پیش‌فرض (رنگ/ضخامت/سبک) جدا از Line دارند؛ هر ویرایش روی چارت ذخیره می‌شود. اولین بار رنگ‌شان از Line می‌آید.
   - تب Draw از ۸ به ۱۰ دکمه (۵ ستون × ۲ ردیف) رفت.
3. **Weekly Map ادامه‌دار**: هر وقت قیمت از بالاترین/پایین‌ترین خط رد شود، یک گام ۲۵٪ دیگر اضافه می‌شود (WH+50٪، WH+75٪، … / WL−50٪، …)، تا همیشه یک خط جلوی قیمت باشد. سطوح اضافه‌شده بعد از برگشت قیمت می‌مانند؛ با هفته‌ی جدید ریست می‌شوند. سقف ۴۰ گام برای هر طرف.
   - اضافه‌ها با ورودی‌های `WMAP_ShowExtensions` و `WMAP_ShowLabels` کنترل می‌شوند.

EA بدون تغییر (v75.3).

## تست‌ها
- D1: Hub را کامپایل و روی XAUUSD بگذار؛ تب Draw را باز کن → ۱۰ دکمه، دو دکمه‌ی جدید «Horizontal Line» و «Dash Line» با متن خوانا و بدون بیرون‌زدگی.
- D2: Horizontal Line → یک کلیک روی چارت → خط افقی از آن نقطه به راست ادامه دارد؛ بعد از رسم دکمه غیرفعال می‌شود.
- D3: Dash Line → دو کلیک (پیش‌نمایش با ماوس دنبال شود) → خط‌چین نازک؛ با Shift زاویه قفل شود.
- D4: رنگ یک Horizontal Line را عوض کن (دابل‌کلیک → Properties)، یک خط افقی جدید بکش → با رنگ جدید. رنگ دکمه‌ی Line و مستطیل‌ها تغییر نکرده باشد. Dash هم همین‌طور.
- D5: تایم‌فریم عوض کن / Hub را ری‌لود کن → رنگ‌های ذخیره‌شده بمانند.
- D6: دکمه‌ی WMAP را روشن کن؛ وقتی قیمت از WH+25٪ بالاتر رفته (یا WL−25٪ پایین‌تر) باید خط/لیبل بعدی (WH+50٪ یا WL−50٪) رسم شده باشد؛ برای تست، در تاریخچه یا هفته‌ای که قیمت از رنج هفته‌ی قبل بیرون زده بررسی کن.
- D7: هیچ خطایی در لاگ نباشد و سه چارت ۳ دقیقه بیکار هم `[RM-PERF]` نداشته باشد.
