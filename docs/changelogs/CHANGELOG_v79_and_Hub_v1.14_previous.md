- از ۸ لول به ۹ لول رفت؛ صرفاً نمایشی — هیچ منطق محاسباتی/اجرایی جدید

### کار چهارم — Candle Timer همیشه‌فعال

- شمارش معکوس کندل حالا مستقیماً از `OnInit()` همیشه فعاله — بدون نیاز به GlobalVariable
- فرمول محاسبه‌ی خودِ کانت‌داون دست‌نخورده موند
- دکمه‌ی **BE REF LINE** به کل عرض ردیف (بدون گپ) گسترش پیدا کرد تا جای خالی رو پر کنه

### کار پنجم — FEAT-030: بازطراحی Measure Move (پنل Utility)
⚠️ **این کار دو مرحله داشت:**
1. تلاش اول (اشتباه): طبق دستور کار اولیه، این ابزار با آبجکت‌های سفارشی (OBJ_TREND + OBJ_RECTANGLE شید‌دار) بازسازی شد. بعداً مشخص شد این توضیحات در واقع برای یک ابزار **جدید** در Executive Hub بوده، نه این ابزار در RiskManager EA.
2. اصلاح نهایی: ابزار به فرمت اصلی‌اش (native `OBJ_FIBO`، دقیقاً مثل قبل — قابل‌درگ، fine-tune کامل) برگردوندیم. فقط لول‌ها/لیبل‌ها به‌روز شدن:

| value | label |
|---|---|
| -1.0 | measure |
| -0.25 | range buffer |
| 0.0 | high |
| 0.5 | mid range |
| 1.0 | low |
| 1.25 | range buffer |
| 2.0 | MEASURE |

- **بهبود اضافه:** چون OBJ_FIBO لول ۰ رو همیشه روی کلیک اول و لول ۱ رو روی کلیک دوم می‌ذاره (نه بر اساس مقدار عددی)، قبل از ساخت آبجکت anchor ها با MathMax/MathMin مرتب می‌شن — پس "high" همیشه واقعاً بالاتره و "low" همیشه واقعاً پایین‌تره، صرف‌نظر از ترتیب کلیک تریدر
- **اصلاح نهایی سبک خط:** همه‌ی ۷ لول به خط‌چین ریز (`STYLE_DOT`) تغییر کردن (به‌جای ترکیب قبلی DASH/DASHDOTDOT)

## بخش ۲ — Executive Hub v1.14

### ابزار جدید: RANGE (پنل Draw)
همون طراحی گرافیکی‌ای که اشتباهاً برای RiskManager EA ساخته شده بود، به جای درستش منتقل شد:

- **دکمه:** «RANGE» — در فضای خالیِ زیر سه دکمه‌ی مادر (Ind+/Label+/Draw−)، عرضش کل اون فضا رو پر می‌کنه
- **رفتار:** آرم می‌شه (خاکستری↔فیروزه‌ای) → دو کلیک روی چارت (نقطه‌ی اول، نقطه‌ی دوم) → ترسیم نهایی، دقیقاً هم‌الگوی ابزار Line موجود
- **ساختار گرافیکی:** ۷ خط (`OBJ_TREND`، خط‌چین ریز) + ۲ کادر مستطیلی شید‌دار (`OBJ_RECTANGLE`، پرشده) + ۷ لیبل متنی
- **رنگ‌ها (زنده، از همین مجموعه‌ی Draw خونده می‌شن):**
  - خط‌ها → هم‌رنگ **Rectangle 2**
  - کادر بالا (سمت high/measure) → هم‌رنگ **Shade 4**
  - کادر پایین (سمت low/MEASURE) → هم‌رنگ **Shade 3**
- **جهت‌گیری خودکار:** high/low بر اساس مقدار عددی واقعی تعیین می‌شن (نه ترتیب کلیک) — همون منطق MathMax/MathMin نسخه‌ی EA
- **سلکت گروهی:** دقیقاً مکانیزم ابزار Path — کلیک روی هر جزئی از یک نمونه‌ی RANGE، کل ۱۶ زیرآبجکتش (۷خط+۷لیبل+۲مستطیل) با هم سلکت می‌شن؛ یک Delete کل مجموعه رو پاک می‌کنه، بدون نیاز به تک‌تک سلکت‌کردن
- **نام‌گذاری روی چارت:** اشکال نهایی با پیشوند `DrawPanel_Range_<timestamp>_<seq>` ساخته می‌شن

### فیکس روانی (lag) — سه دور اصلاح
گزارش شد ابزار موس رو راحت دنبال نمی‌کرد. ریشه‌یابی و رفع شد:
1. هر تیک پیش‌نمایش (هر ۱۵۰ms، هم‌نرخ Line/Path) داشت هر ۱۶ زیرآبجکت رو delete+recreate می‌کرد → تبدیل به الگوی «فقط اگه نبود بساز، وگرنه فقط آپدیت کن» (همون الگوی HLine/PreviewHLine پروژه)
2. حین کشیدن (قبل از کلیک دوم) فقط ۷ خط دیده می‌شن — دو کادر مستطیلی (سنگین‌ترین بخش، چون FILL+BACK) اصلاً ساخته نمی‌شن تا بعد از کلیک دوم
3. throttle نرخ آپدیت (۱۵۰ms) از اول با بقیه‌ی ابزارهای رسم این پنل یکی بود — تأیید شد که مشکل از نرخ نبود، از حجم کاری هر تیک بود
