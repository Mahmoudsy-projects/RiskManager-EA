# v100 — FEAT-046: باکس‌های History توخالی با کلیک روی مارکر
- باکس‌های History مثل قبل پر رسم می‌شوند.
- با کلیک روی مارکر Entry/Exit یک معامله (همان کلیکی که لیبل #تیکت را نشان می‌دهد)، باکس‌های TP و SL همان زنجیره توخالی (فقط کادر، ضخامت ۲، جلوی بقیه) می‌شوند تا باکس‌های زیر/همپوشان قابل‌دیدن باشند. کلیک دوباره (لیبل مخفی) → دوباره پر.
- وضعیت توخالی بین بازرسم History (معامله‌ی تازه/تغییر روز/تایم‌فریم) حفظ می‌شود.
- فقط وقتی History روشن باشد اثر دارد (Markers هم باید روشن باشد تا مارکرها کلیک شوند).
