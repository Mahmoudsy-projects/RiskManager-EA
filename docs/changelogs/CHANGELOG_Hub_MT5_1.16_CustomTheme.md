# Hub MT5 1.16 — تم Custom به‌جای Original   [کامپایل نشده]
(شامل 1.15: حذف Print تشخیصی [HUB-PATHGROUP])

دکمه‌ی «Original» از کشوی Theme برداشته شد. جایش (ستون ۴ ردیف ۲) سه دکمه‌ی کوچک آمد:
- **Custom** : رنگ‌های ذخیره‌شده را روی چارت اعمال می‌کند. خالی باشد خاکستری است و فقط پیام لاگ می‌دهد. وقتی ذخیره دارد، رنگ دکمه = رنگ کندل صعودی ذخیره‌شده (پررنگ = فعال).
- **S** (Save) : رنگ‌های فعلی چارت را به‌عنوان Custom ذخیره می‌کند.
- **R** (Reset) : Custom ذخیره‌شده را پاک می‌کند.

ذخیره‌شده‌ها: پس‌زمینه، Foreground، Grid، Bar Up/Down، کندل صعودی/نزولی، Line، Volume، Ask، Stop Level، Bid، Last + نمایش Grid، Shift، خط Ask، حالت نمودار.
ذخیره‌سازی در GlobalVariable سراسری ترمینال است: روی همه‌ی چارت‌ها و نمادها یکی است، با بستن ترمینال و تغییر تایم‌فریم می‌ماند و فقط با R پاک می‌شود.
نسخه‌ی ایمنِ رنگ‌های اولیه‌ی هر چارت (آبجکت مخفی) همچنان قبل از اولین تم ذخیره می‌شود ولی دکمه‌اش حذف شده.

روش استفاده: ۱) با F8 رنگ‌ها را تنظیم کن (یا یکی از تم‌ها را بزن و F8 اصلاحش کن) ۲) S را بزن ۳) از این به بعد روی هر چارت Custom را بزن.
