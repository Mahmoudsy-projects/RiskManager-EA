# Hub MT5 1.14 — Path ۲ / Line ۲ + ترتیب شماره‌ی تم‌ها   [کامپایل نشده]

(این بسته شامل تمام تغییرات Hub 1.13 هم هست: تم‌های ۸–۱۰، تم ۴، دکمه‌های هم‌اندازه.)

## ابزارهای جدید نوار Draw
- دو دکمه‌ی جدید **Path 2** (پیش‌فرض قرمز) و **Line 2** (پیش‌فرض آبی)، در ستون جدیدی بعد از Path/Line.
- پیش‌فرض **Path** از خاکستری به **آبی** عوض شد (فقط وقتی قبلاً رنگ دیگری برایش ذخیره نکرده باشید؛ اگر ذخیره شده باشد همان می‌ماند و کافی است یک‌بار رنگ یک Path را در Properties آبی کنید). پیش‌فرض Line همان قرمز است.
- هر دکمه رنگ، ضخامت و استایل پیش‌فرض مستقل خودش را دارد. با عوض‌کردن این‌ها در Properties یک شیء کشیده‌شده، پیش‌فرض همان دکمه ذخیره می‌شود (مثل Horizontal/Dash).
- Path 2 مثل Path چندنقطه‌ای است (دابل‌کلیک = پایان) و کل زنجیره با یک کلیک انتخاب می‌شود. Line 2 دو‌کلیکه با Shift-snap مثل Line.
- عرض نوار Draw یک ستون بیشتر می‌شود.

## جابه‌جایی گروهی Path (رفع ایراد)
در MT4 با کشیدن یک قطعه‌ی Path کل مسیر جابه‌جا می‌شد ولی در MT5 فقط همان قطعه. دلیل محتمل: اسنپ‌شات موقعیت قطعه‌ها فقط هنگام رویداد کلیک ساخته می‌شد و اگر آن رویداد قبل از شروع درگ نمی‌رسید، گروه حرکت نمی‌کرد. حالا موقعیت همه‌ی قطعه‌های Path و Path 2 همیشه نگه‌داشته می‌شود (هنگام ساخت، شروع Hub و بعد از هر درگ) و کشیدن هر قطعه کل همان مسیر را می‌برد. کشیدن فقط یک سر قطعه فقط همان قطعه را تغییر می‌دهد. در لاگ خطی با برچسب `[HUB-PATHGROUP]` ثبت می‌شود تا اگر هنوز درست نبود علتش دیده شود.

## ترتیب شماره‌ی تم‌ها
ردیف بالا: ۱ ۲ ۳ ۴. ردیف پایین: ۵ ۶ ۷ (زیر Ind/Label/Draw/Theme) سپس ۸ ۹ ۱۰ و Original. شماره‌ها پشت‌سرهم خوانده می‌شوند.

## تست‌ها
1. تب Draw: دکمه‌های Path 2 (قرمز) و Line 2 (آبی) دیده شوند، بقیه‌ی دکمه‌ها سر جای خود.
2. Path 2 را بزنید و چند نقطه بگذارید، دابل‌کلیک: خط قرمز؛ کلیک روی آن کل زنجیره را انتخاب کند. Path (۱) آبی بکشد و مستقل باشد.
3. Line 2 و Line: هر کدام با رنگ خودش (آبی/قرمز)، پیش‌نمایش هم‌رنگ.
4. رنگ/ضخامت یک Line 2 کشیده‌شده را عوض کنید، سپس یک Line 2 تازه بکشید: با تنظیم جدید باشد؛ Line (۱) تغییر نکند. همین برای Path 2.
5. ری‌استارت Hub/تغییر تایم‌فریم: رنگ/ضخامت‌ها بمانند.
6. یک Path چندقطعه‌ای (و یک Path 2) بکشید، روی یک قطعه کلیک و آن را بکشید: کل مسیر با هم جابه‌جا شود. کشیدن فقط یک سر قطعه، فقط همان قطعه را تغییر دهد. اگر درست نشد، لاگ Experts (خطوط HUB-PATHGROUP) را بفرستید.
7. تب Theme: ترتیب ۱–۴ بالا، ۵–۷ زیر مادرها، ۸–۱۰ و Original ردیف پایین شبکه؛ همه هم‌اندازه و بدون جای خالی.
