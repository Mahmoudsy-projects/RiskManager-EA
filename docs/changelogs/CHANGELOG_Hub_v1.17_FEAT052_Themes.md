# CHANGELOG Hub v1.17 — FEAT-052: دکمه‌ی تم چارت (Theme)

> ⚠️ **کامپایل نشده.** فقط بالانس `{}` `()` `[]` (با حذف رشته‌ها و کامنت‌ها) و diff با Hub v1.16 بررسی شده. قبل از استفاده در MetaEditor کامپایل و روی **دمو** (XAUUSD H1) تست کنید. اکانت لایو تا تصمیم شما روی Hub قبلی بماند.

## چه اضافه شد
- دکمه‌ی مادر چهارم **Theme** کنار Indicator / Label / Draw. کشوی آن ۷ دکمه‌ی شماره‌دار (۱..۷) + دکمه‌ی **Original** دارد.
- کلیک روی تم: یک‌بار و فوری روی **چارت فعلی** اعمال می‌شود (۱۱ رنگ + Grid خاموش، Shift روشن، Candlestick، Ask line روشن) و فقط **یک** `ChartRedraw()` زده می‌شود. هیچ تایمر/پولینگ جدیدی نیست؛ بعد از اعمال، هیچ کدی اجرا نمی‌شود تا کلیک بعدی.
- رنگ دکمه‌ی هر تم = رنگ Bull همان تم؛ متن سیاه/سفید بر اساس روشنایی. دکمه‌ی تم ۳ (Bull سبز تیره) حاشیه‌ی روشن دارد؛ تم ۶ چون Bull آن روشن است (211) روی پنل تیره خودش دیده می‌شود. دکمه‌ی فعال همان استایل «فعال» فعلی Hub را دارد.
- کشوها دوبه‌دو انحصاری‌اند (باز شدن Theme بقیه را می‌بندد و برعکس). وضعیت باز/بسته مثل بقیه‌ی کشوها پایدار است.
- **Original**: رنگ/تنظیمات چارت قبل از اولین تم، یک‌بار و قبل از اعمال هر چیز، در یک آبجکت مخفی ذخیره می‌شود و هرگز بازنویسی نمی‌شود. دکمه‌ی Original همان را برمی‌گرداند و هیچ تمی فعال نمی‌ماند.
- **کنتراست خودکار** برای رنگ‌های ثابت Hub (`Theme_ContrastSafe`، هم‌سبک MTFCP: اختلاف روشنایی حداقل ۴۵): Draw tools، Label، Measure، Weekly Map، EMA Overlay، POC، SOB، NYE، MTFCP. رنگ‌هایی که قبلاً خودکار بودند همان ماندند و رنگ پیش‌فرض روی تم فعلی شما تقریباً تغییر نمی‌کند (فقط وقتی کنتراست کم باشد جابه‌جا می‌شود).

## ذخیره‌ی Original
- آبجکت: `PFX + "ThemeOrig"` (OBJ_LABEL، `OBJPROP_HIDDEN=true`، `OBJ_NO_PERIODS`، غیرقابل انتخاب، خارج از صفحه)، متن = رشته‌ی base64 (۵۱ کاراکتر) از ۱۱ رنگ + grid/shift/mode/ask.
- با تغییر تایم‌فریم / ری‌لود Hub / ریستارت ترمینال می‌ماند (با چارت ذخیره می‌شود). `OnDeinit` آن را **پاک نمی‌کند**؛ با برداشتن Hub هم می‌ماند تا اگر Hub دوباره اتچ شد Original کار کند. حذف دستی: Objects List (Ctrl+B) → Show hidden → `...ThemeOrig`.
- اگر ذخیره ممکن نبود (خطا/متن کوتاه‌شده) تم **اعمال نمی‌شود** و لاگ می‌دهد.

## تابع هوک‌شده‌ی بازرنگ یک‌باره
`Theme_RecolourOnce()` همان توابعی را یک‌بار صدا می‌زند که شاخه‌ی `CHARTEVENT_CHART_CHANGE` و ماژول‌ها دارند: `EMA_ApplyGrayscaleColors`, `WMAP_DrawAll`, `POC_RecolourLevels`, `SOB_Recalculate`, `NYE_Recalculate`, `MTFCP_DrawAll` (+countdown). چون `ChartSetInteger` ممکن است ناهمگام باشد، در این لحظه رنگ‌های تازه از `Hub_ChartBg/Fg/Bull/Bear()` (override موقت) خوانده می‌شود.
