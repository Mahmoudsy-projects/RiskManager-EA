# EA MT5 v75.7 — رفع فلش سطوح پیش‌فرض فیبو (R/R و Measure Move)

NOT COMPILED — لطفاً کامپایل و تست کنید. Hub بدون تغییر (1.12). شامل v75.5 و v75.6 هم هست.

## علت (تشخیص از روی کد)
- بعد از کلیک اول، پیش‌نمایش با **هر حرکت موس** حذف و دوباره ساخته می‌شد (`ObjectDelete` + `ObjectCreate`).
- هر `ObjectCreate(OBJ_FIBO)` اول با **سطوح پیش‌فرض فیبو** (۰ / ۲۳.۶ / ۳۸.۲ / ۵۰ / ۶۱.۸ / ۱۰۰ ...) و رنگ پیش‌فرض ساخته می‌شود و فقط *بعدش* سطوح R/R یا Measure Move جایگزین می‌شود.
- ترد گرافیکی ترمینال مستقل از EA چارت را رسم می‌کند؛ اگر وسط این فاصله‌ی کوتاه رسم کند، سطوح پیش‌فرض یک لحظه دیده می‌شوند (فلش) و بعد با سطوح درست عوض می‌شوند. هم روی ساخت نهایی و هم روی هر فریم پیش‌نمایش رخ می‌داد.
- (باگ قدیمی و در MT4 هم وجود دارد؛ MT4 فریز است و دست نخورد.)

## اصلاح
1. پیش‌نمایشِ موجود دیگر حذف/ساخته نمی‌شود؛ فقط دو نقطه‌اش جابه‌جا می‌شود (کمترین فلش + سبک‌تر).
2. شیء تازه بلافاصله بعد از ساخت روی هیچ تایم‌فریمی دیده نمی‌شود (`OBJ_NO_PERIODS`) و فقط بعد از تنظیم همه‌ی سطوح قابل‌مشاهده می‌شود.

## تست‌ها
- X1: R/R بگذارید؛ در طول کشیدن پیش‌نمایش و لحظه‌ی کلیک دوم هیچ سطح فیبوی پیش‌فرض نباید پرید.
- X2: همین برای Measure Move.
- X3: بعد از قرارگیری، ابزار قابل drag و ویرایش باشد (هر دو نقطه).
- X4: چند R/R و Measure Move پشت سر هم بگذارید؛ همه‌ی آن‌ها در همه‌ی تایم‌فریم‌ها دیده شوند.
- X5: لغو کردن (Esc/غیرفعال‌کردن دکمه) در میانه‌ی پیش‌نمایش، چیزی روی چارت باقی نگذارد.
