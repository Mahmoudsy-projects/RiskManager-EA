# DayBias Data Script (MT5 / XAUUSD)

اسکریپتِ فقط-خواندنیِ MT5 که کلِ تاریخچه‌ی M5 موجود را روزبه‌روز پیمایش می‌کند و برای هر روزِ معاملاتی یک
ردیفِ CSV با لیبل‌های Day Bias Scorecard + مقادیرِ خام تولید می‌کند. هیچ اردری ارسال نمی‌شود. خروجی برایِ
اعتبارسنجیِ آماریِ فیلترِ جهتِ روز (سبز/زرد/قرمز) استفاده می‌شود.

سندِ کاملِ دستورکار و تعریف‌های فریزشده: [`docs/DayBias_FrozenDefinitions.md`](docs/DayBias_FrozenDefinitions.md)

## ساختار

```
MQL5/
  Include/
    RM_SessionTime.mqh          کپیِ canonical — فقط زمان‌بندیِ سشن (NY calendar + DST + آفستِ پایدارِ سرور)
    DayBias_BoxLayer.mqh        محاسبه‌ی OHLC پنجره‌های سشن روی M5 (مستقل، قابلِ استفاده در پروژه‌های دیگر)
    DayBias_DetectionLayer.mqh  تشخیصِ LP / NY Edge / رنگِ روز طبقِ تعریف‌های فریزشده
    DayBias_CsvWriter.mqh       فرمتِ ستون‌ها و هدرِ CSV
  Scripts/
    DayBias_DataScript.mq5      اسکریپتِ اصلی (OnStart)
docs/
  DayBias_FrozenDefinitions.md  کپیِ تعریف‌های فریزشده + یادداشتِ تفسیریِ رنگِ روز
```

## نصب و اجرا

1. پوشه‌ی `MQL5/Include/*.mqh` را در `<Data Folder>/MQL5/Include/` کپی کنید.
2. `MQL5/Scripts/DayBias_DataScript.mq5` را در `<Data Folder>/MQL5/Scripts/` کپی کنید.
3. در MetaEditor کامپایل کنید (بدونِ خطا باید کامپایل شود).
4. یک چارتِ XAUUSD باز کنید، تاریخچه‌ی M5 را تا حدِ ممکن به عقب اسکرول کنید تا از سرور دانلود شود
   (یا از Trading > History در ترمینال، یا با اسکرول در چارتِ M5).
5. اسکریپت را روی همان چارت درگ کنید. اینپوت‌ها (پنجره‌های سشن) قابلِ تنظیم‌اند؛ دیفالت‌ها طبقِ سند.
6. خروجی: `<Data Folder>/MQL5/Files/DayBias_History_XAUUSD.csv`. خلاصه (تعدادِ روزِ پردازش‌شده/skip شده/
   توزیعِ رنگ‌ها) در تبِ Experts/Journal چاپ می‌شود.

## نکات مهم قبل از استفاده از خروجی

- **پنجره‌ی سشنِ NY روزِ قبل** (برایِ `NY_PrevHigh/Low/Range`) به‌صورتِ `09:00–18:00` به وقتِ نیویورک
  دیفالت شده — طبقِ تأییدِ شما، نه دیفالتِ اولیه‌ی سند (`08:30–15:00`). قابلِ تغییر با اینپوت‌هایِ
  `InpNYPrevStartH/M`, `InpNYPrevEndH/M`.
- **رنگِ روز**: چون سندِ اصلی رأیِ LP و رأیِ NY را روی دو مبنایِ زمانیِ متفاوت تعریف کرده (جزئیات در
  `docs/DayBias_FrozenDefinitions.md`)، یک تفسیرِ مشخص در کد پیاده شده و باید با تستِ راستی‌آزماییِ
  دستیِ بخشِ ۶ (خصوصاً کیسِ ۱۱ اوتِ ۲۰۲۶) تأیید شود.
- `SOB_ProcessOneDay` اصلی در این ریپو موجود نبود؛ لایه‌ی باکس مستقیماً از رویِ توضیحاتِ بخشِ ۲ سند
  (نه از کدِ اصلیِ Hub) پیاده‌سازی شده. تستِ پذیرشِ #۱ (تطابقِ `BoxSize` با لیبلِ SOB روی چارتِ لایو برایِ
  ۱۰ روزِ اخیر) قبل از اعتماد به دیتا باید اجرا شود.
- این ریپو محیطِ MT5 ندارد؛ کد کامپایل/تست نشده و باید در MetaEditor بررسی شود.
