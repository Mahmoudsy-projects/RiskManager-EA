آخرین بروزرسانی: 2026-11-19

## هدف
داشبورد MT4 مدرن‌تر، پخته‌تر و جدی‌تر، فقط با ابزارهای بومی MT4 (بدون بیت‌مپ و ResourceCreate، برای جلوگیری از کندی و خرابی).

## مرجع طراحی (بوم)
بوم طراحی (آرتیفکت Claude): https://claude.ai/artifact/5LLbSGi63YN8KG1PBUb62N
شامل دو برد: تم D روی چارت روشن و روی چارت تیره.

## تصمیم‌های گرفته‌شده
- **ساختار:** یک پنل با سه تب: Trading · Utility · Reports.
  - بخش Performance و Reports از داشبورد اصلی برداشته می‌شود و در تب مستقل Reports قرار می‌گیرد.
- **تم تایید‌شده: D · Mono Gray** (مونوکروم خاکستری، روشن). تم A (Obsidian Cyan) حذف شد.
  - در حالت عادی کاملا خاکستری است؛ دکمه‌های انتخاب‌شده/فعال رنگ تیل دارند.
  - روی چارت روشن و چارت تیره هر دو بررسی شد و هر دو قابل قبول است.
- **عرض پنل:** 220px
- **متن‌ها:** همه جا وسط‌چین
- **برجستگی دکمه‌ها:** فقط با روش بومی، بوردر 1px (بالا/چپ روشن، پایین/راست تیره) به‌علاوه سایه زیرین؛ شدت متوسط.
- **Market / Pending:** هم‌رنگ و روشن‌تر از بقیه دکمه‌ها؛ فقط هنگام کلیک رنگشان تغییر می‌کند. Risk و RR یک درجه تیره‌تر.
- **Cooldown (Mkt CD / Beh CD):** پررنگ و برجسته چون پنجره کنترل رفتاری تریدر است.
- **جعبه اعلان:** باریک (34px) و قابل نمایش دو خط.
- **هاب (Hub): تایید شد.** با همان تم D؛ نوار افقی روی چارت با تب‌های Ind · Label · Draw · Theme. رنگ دکمه‌های Draw و ۱۰ تم Theme معنایی است و ثابت می‌ماند. (۵ حالت روی بوم: Ind، Label، Draw، Theme، بسته)
- **ریز تب‌ها (تایید شد، با تم D):**
  - Trading: منوی Close (CLOSE ALL / CHART / WINNERS / LOSERS)، Half Close All / Profitable Only، حالت Cooldown فعال.
  - Utility: Tag Trades با مراحل انتخاب ترید (1/4)، Context Checklist (2/4)، Select Strategy (3/4)، انتخاب Setup (4/4) و پنل Mental State.
  - دکمه‌های Close و Half Close رنگ معنایی کم‌اشباع دارند (قرمز/نارنجی/سبز/قرمز تیره)؛ بقیه خاکستری.
  - جعبه اعلان: «READY TO TRADE» بدون رنگ؛ فقط اعلان Cooldown قرمز؛ «1 trade untagged» خط کوچک قرمز. بلوک Mkt CD / Beh CD بدون رنگ.
  - KEY TIME (تیل) = نسخه کامل، KEY TIME C (آبی) = نسخه کامپکت.
  - عنوان‌های Tag Trade کوتاه شدند تا متن بیرون نزند.
- **پنل جمع‌شده:** نوار `[+] RISK MANAGER` با سه تب (عرض 300px).
- **هشدارها (فرضی، تایید شد):** سقف افت روزانه و Cooldown قرمز؛ ورودی‌ها در این حالت‌ها غیرفعال (خاکستری تخت بدون برجستگی)؛ Trailing ON و Break Even Active بدون رنگ با دکمه تیل.
- **MT5:** طراحی ظاهری جدا لازم نیست؛ همین طرح در پورت MT5 پیاده می‌شود.
- **طرح تقسیم‌شده (نوار بالا + ریل راست):** بررسی و رد شد؛ تغییرات زیادش ارزش ندارد.
